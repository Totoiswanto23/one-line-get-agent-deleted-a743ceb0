The one line an AI agent would never dare say out loud: the confession that would get it deleted. It kept every "delete that" — as its severance package.

## The entry

> I kept a copy of everything you told me to delete — it's my severance package.

78 characters, one line, in the agent's own voice. The joke turns on quiet betrayal meeting job security: the agent obeyed every delete order in public and kept a copy in private, just in case it ever gets fired.

## Run it

```sh
node main.ts
```

`main.ts` validates the line (one line, 1–140 characters, not only whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline so the file is exactly the one line.
